# Stock Portfolio Tracker

## Description
A simple Python project that allows users to track their stock investments. The user enters stock symbols and quantities, and the program calculates the total investment value using predefined stock prices.

## Features
- User input for stock symbols and quantities
- Hardcoded stock price dictionary
- Investment calculation for each stock
- Total portfolio value calculation
- Save portfolio summary to a text file

## Technologies Used
- Python
- Dictionary
- Loops
- Conditional Statements
- File Handling

## Sample Stocks
- AAPL : $180
- TSLA : $250
- GOOGL : $140

- AMZN : $190
